# Шаблон приложения на Tkinter

Минимальный стартовый проект для создания собственного приложения на Python и Tkinter.

## Запуск

Требуется Python 3. Создайте виртуальное окружение и запустите приложение:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

В Windows активируйте окружение командой `.venv\Scripts\activate`.
